# Скрывать транспорт Jira за нормализованными ошибками

MCP-потребитель получает только безопасные `{ code, message, details? }`, где `code` принадлежит контролируемому перечислению, а `details` соответствует схеме конкретной ошибки. HTTP-статусы, URL, сырые ответы Jira и внутренние причины остаются внутри сервера: это уменьшает диагностичность для потребителя, но сохраняет границу интеграции и не раскрывает протокол общения инструмента с Jira.
