# MCP-интеграция с Jira

Контекст описывает понятия, через которые MCP-потребители читают и изменяют задачи Jira Server/Data Center.

## Language

**Переход статуса**:
Один разрешённый текущим workflow Jira переход задачи в целевой статус. Статус задачи не считается полем, доступным для прямой записи.
_Avoid_: прямая смена поля `status`

**Целевой статус**:
Запрошенный потребителем статус задачи. Он сопоставляется по имени с назначением доступного перехода после удаления крайних пробелов и без учёта регистра. Для удобства потребитель также может выбрать доступный переход по его имени. Совпадение запроса с текущим статусом имеет приоритет и не выполняет переход.

**Доступный переход**:
Одношаговый переход статуса, который текущий workflow Jira разрешает для задачи и текущего пользователя.

**Контролируемая ошибка**:
Безопасная типизированная ошибка для потребителя с нормализованным кодом и контрактными данными. Сырые ответы Jira и транспортные сведения в неё не входят.

**Проверенный переход**:
Переход статуса, после которого отдельное чтение задачи подтвердило целевой статус по его идентификатору. Успешный ответ не гарантирует, что статус не изменится позднее.

**Неизвестный результат перехода**:
Состояние после попытки перехода, которое не удалось подтвердить отдельным чтением задачи. Оно отличается от наблюдаемого несовпадения, при котором чтение успешно, но фактический статус не является целевым.
