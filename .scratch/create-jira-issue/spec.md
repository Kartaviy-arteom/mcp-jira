# Создание задачи Jira

MCP-инструмент `create-jira-issue` создаёт обычную задачу типа `FRONT` в существующем проекте «Система управления заказами - OMS ЗЧ (Агора)» (`OMSAGORA`). Проект и тип заданы внутри инструмента: вызывающий передаёт обязательные `summary` (тему) и `description` (описание), а также необязательные `epicKey` и `releaseName`. К теме инструмент добавляет обязательный префикс `[FE] `; если он уже указан, второй префикс не добавляется. Пробелы вокруг темы убираются, описание передаётся без изменения. Тема без текста после префикса и описание из одних пробелов невалидны.

Перед созданием инструмент проверяет существование проекта по ключу и наличие типа `FRONT` среди доступных для создания в нём типов. Сопоставление имени не зависит от регистра: в текущей Jira тип называется `Front`. Он не создаёт проекты или типы.

Epic Link обязателен. Если `epicKey` не передан, используется существующий эпик `OMSAGORA-350` («1. Эпик 1.1. Стандартный процесс формирования заказа»). Переданный ключ должен указывать на существующий эпик проекта `OMSAGORA`. ID пользовательского поля Epic Link берётся из метаданных создания задачи; новые эпики не создаются.

Если передано `releaseName`, инструмент выбирает ровно одну версию проекта с таким именем, `archived: false` и `released: false`. При отсутствии или неоднозначности выбора задача не создаётся. Если имя не передано, поле `fixVersions` не задаётся. Новые релизы не создаются. После успешного `POST /rest/api/2/issue` возвращается только ключ вида `OMSAGORA-<номер>`.

Если конфигурация Jira потребует другие поля, их определят при отладке и добавят отдельным изменением. Текущая версия не подставляет значения таких полей автоматически. Ошибки Jira возвращаются через существующий нормализованный контракт.

Решение основано на [REST API Jira Server 9.12](https://docs.atlassian.com/software/jira/docs/api/REST/9.12.12/#api/2/issue-createIssue) и [примерах Atlassian для Data Center](https://developer.atlassian.com/server/jira/platform/jira-rest-api-examples/#creating-an-issue-using-a-project-key-and-field-names). Ссылка на 9.12.23 из `AGENTS.md` недоступна для автоматического просмотра; использованы документы той же ветки 9.12 и официальные примеры.
