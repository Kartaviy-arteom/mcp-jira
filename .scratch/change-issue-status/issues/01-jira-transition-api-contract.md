## Question

Каков точный контракт Jira Server/Data Center 9.12.23 REST API v2 для чтения доступных переходов, определения целевого статуса и обязательных полей, выполнения перехода и проверки результата, включая успешные HTTP-ответы и документированные ошибки?

## Answer

Статус меняется через workflow transition: прочитать исходный статус, получить доступные переходы с `expand=transitions.fields`, выбрать единственный переход по `to.name`, отклонить требующий обязательных полей переход, отправить минимальный `POST` с `transition.id` и после `204` обязательно повторно прочитать статус. Полный контракт, HTTP-ответы, риски гонки и ссылки на официальную Jira REST API 9.12.23: [jira-transition-api-9.12.23.md](../research/jira-transition-api-9.12.23.md).
