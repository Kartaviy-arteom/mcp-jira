# 05: Добавить безопасную загрузку изображения

**What to build:** Пользователь загружает выбранное изображение только из вложений указанной задачи и получает MCP image-блок вместе с безопасными структурированными метаданными.

**Blocked by:** 04: Добавить список вложений задачи

**Status:** ready-for-agent

- [ ] Строгий вход принимает нормализованный `issueKey` и проверенный числовой `attachmentId`.
- [ ] Перед загрузкой инструмент читает вложения задачи и проверяет наличие выбранного ID; при отсутствии возвращает `ATTACHMENT_NOT_FOUND` без загрузочного запроса.
- [ ] Неподдерживаемый MIME-тип отклоняется как `UNSUPPORTED_ATTACHMENT_TYPE`, размер метаданных свыше `5 * 1024 * 1024` — как `ATTACHMENT_TOO_LARGE`.
- [ ] URI `content` принимается только при совпадении HTTP/HTTPS-протокола, origin, базового пути настроенной Jira и выбранного вложения; внешний или несовместимый URI отклоняется.
- [ ] Общий Jira-клиент получает только проверенный внутренний endpoint и сохраняет авторизацию, безопасные ошибки и общий timeout без архитектурной переделки.
- [ ] Канонический `Content-Type` совпадает с MIME-типом метаданных после удаления параметров и нормализации регистра.
- [ ] Корректный `Content-Length` проверяется до чтения, а поток прерывается сразу после превышения лимита независимо от наличия заголовка.
- [ ] Загруженные байты подтверждаются сигнатурой PNG, JPEG или WebP; несовпадение типа, заголовка или сигнатуры даёт `RESPONSE_FORMAT_ERROR`.
- [ ] Ответ содержит image-блок с base64 и каноническим MIME-типом, а `structuredContent` — только ключ задачи, ID, имя, MIME-тип и размер.
- [ ] Бинарные данные не записываются на диск или в лог и не дублируются в текстовом JSON.
- [ ] В безопасную таксономию добавлены `ATTACHMENT_TOO_LARGE` и `UNSUPPORTED_ATTACHMENT_TYPE` без утечки исходных деталей.
- [ ] Все разрешённые форматы, URI-проверки, оба способа превышения размера, сигнатуры, timeout и MCP-ответ покрыты тестами через публичный шов; транспортные случаи — через интерфейс клиента.
- [ ] Линтинг, форматирование, типы, тесты и сборка проходят.
