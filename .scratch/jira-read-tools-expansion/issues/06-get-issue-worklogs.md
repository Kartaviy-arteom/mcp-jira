# 06: Добавить анонимную сводку worklog

**What to build:** Пользователь получает по задаче полную агрегированную сводку затраченного времени, количества worklog и участников без имён, логинов, идентификаторов и комментариев сотрудников.

**Blocked by:** 01: Расширить получение Jira-задачи

**Status:** ready-for-agent

- [ ] Строгий вход использует общий нормализованный и проверенный `issueKey`.
- [ ] Инструмент выполняет один read-only запрос к официальному endpoint worklog Jira Server/Data Center 9.12.23.
- [ ] Полнота ответа подтверждается равенством `worklogs.length` и `total`; несовпадение отклоняется как `RESPONSE_FORMAT_ERROR`.
- [ ] `totalTimeSeconds` равен сумме всех `timeSpentSeconds`, `worklogsCount` — числу записей, `contributorsCount` — числу уникальных участников.
- [ ] Для внутренней уникальности используется первый доступный идентификатор в порядке `key`, `name`, с включением типа идентификатора в ключ.
- [ ] Если у записи нет ни `key`, ни `name`, результат отклоняется как `RESPONSE_FORMAT_ERROR` без попытки угадать число участников.
- [ ] Ответ содержит только `issueKey`, `totalTimeSeconds`, `contributorsCount`, `worklogsCount`; авторы, идентификаторы, `displayName`, комментарии и отдельные записи отсутствуют.
- [ ] Внутренние идентификаторы существуют только во время вызова, не логируются и не включаются в ошибки.
- [ ] Отсутствующая задача возвращает безопасный `ISSUE_NOT_FOUND`; выходная схема подключена к MCP Framework.
- [ ] Пустой ответ, сумма времени, дедупликация, разные пространства идентификаторов, отсутствующий автор и неполный ответ покрыты тестами через MCP-интерфейс.
- [ ] Линтинг, форматирование, типы, тесты и сборка проходят.
