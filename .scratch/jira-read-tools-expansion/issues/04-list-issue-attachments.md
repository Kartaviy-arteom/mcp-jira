# 04: Добавить список вложений задачи

**What to build:** Пользователь получает метаданные всех вложений указанной задачи без скачивания содержимого и сразу видит, какие изображения можно безопасно открыть следующим вызовом.

**Blocked by:** 01: Расширить получение Jira-задачи

**Status:** ready-for-agent

- [ ] Строгий вход использует общий нормализованный и проверенный `issueKey`.
- [ ] Jira запрашивается только на чтение задачи с полем вложений; содержимое файлов не скачивается.
- [ ] Ответ всегда содержит массив `attachments` с `id`, `filename`, `mimeType`, `size`, `supported`.
- [ ] Числовой ID извлекается из документированного URI `self`; несовместимый URI отклоняется как `RESPONSE_FORMAT_ERROR`.
- [ ] `supported: true` устанавливается только для канонических `image/png`, `image/jpeg`, `image/webp`; остальные вложения остаются в списке с `supported: false`.
- [ ] Отсутствующая задача возвращает безопасный `ISSUE_NOT_FOUND`; несовместимые метаданные — `RESPONSE_FORMAT_ERROR`.
- [ ] Публичная выходная схема подключена к MCP Framework и результат доступен в `structuredContent`.
- [ ] Пустой список, поддерживаемые и неподдерживаемые типы, извлечение ID и ошибочные URI покрыты тестами через MCP-интерфейс.
- [ ] Линтинг, форматирование, типы, тесты и сборка проходят.
